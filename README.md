# Banking System

A modern Python-based Banking Management System built using Flask.
This project provides core banking functionalities such as user authentication, transaction management, database handling, and a clean frontend interface.

---

## Features

* User Authentication System
* Deposit & Withdrawal Operations
* Transaction Management
* Database Integration
* Flask Backend
* Static Frontend Files
* Secure Banking Workflow
* Simple and Clean UI

---

## Technologies Used

* Python
* Flask
* HTML
* CSS
* SQLite
* JavaScript

---

## Project Structure

```bash
banking-system/
│
├── auth/                 # Authentication related files
├── database/             # Database handling modules
├── static/               # CSS, JS, images
├── transactions/         # Transaction management
│
├── app.py                # Main Flask application
├── requirements.txt      # Project dependencies
├── banking.db            # Database file
├── core_banking.db       # Core banking database
└── README.md             # Project documentation
```

---

## Installation

### 1 Clone the Repository

```bash
git clone https://github.com/yourusername/banking-system.git
```

---

### 2 Move into Project Folder

```bash
cd banking-system
```

---

### 3 Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 4 Run the Application

```bash
python app.py
```

---

## Usage

After running the server, open your browser and visit:

```bash
http://127.0.0.1:5000
```
